# Сумісність зі станціями BLUETTI

BluettiWidget розпізнає **29 моделей** із зафіксованої версії бібліотеки
Bluetooth-протоколу. Робота залежить від прошивки, адаптера Bluetooth у Windows
і показників, які надає станція.

| Стан підтримки | Моделі |
| --- | --- |
| Моніторинг і повторне підключення перевірено на фізичній станції | AC180P |
| Експериментальна підтримка, лише читання | AC2A, AC2P, AC50B, AC60, AC60P, AC70, AC70P, AC180, AC180T, AC200L, AC200M, AC200PL, AC300, AC500, AP300, EB3A, EL10, EL100V2, EL30V2, EP500, EP500P, EP600, EP760, EP800, EP2000, Handsfree 1, PR30V2, PR100V2 |

Для незашифрованої AC180P реалізовано керування виходами AC/DC і режимом
заряджання. Фізичне перемикання в цьому проєкті ще не перевірено.
Зашифровані з’єднання працюють лише для читання. Відсутні показники
позначаються рискою; у деталях видно дані, які фактично повертає станція.

## Як розпізнається модель

Назва, яку передає Bluetooth-пристрій, зіставляється з відомою моделлю та
можливим числовим суфіксом. Використовується власна карта регістрів моделі
з `bluetti-bt-lib`. Для пошуку потрібне поле заряду. Нові профілі типово
отримують лише читання. Для невідомої моделі спочатку потрібна перевірена
карта протоколу.

## Ємність акумулятора та нові моделі

Типова ємність AC180P — 1440 Вт·год, AC180 — 1152 Вт·год. Для розпізнаної
моделі можна вказати встановлену ємність у секції `[capacity_wh]` локального
`settings.ini`, після чого перезапустити програму.
[Зразок налаштувань](../settings.example.ini):

```ini
[capacity_wh]
AC180=1152
```

Для станцій із додатковими акумуляторами вкажіть загальну встановлену ємність.
Розрахунок часу потребує відомої ємності, показника навантаження та відсутності
вхідного живлення.

Для моделі, яка вже є в бібліотеці, уточнення в `models.py` потрібні лише
для ємності, назв полів або груп регістрів. Для моделі поза бібліотекою
спочатку додайте та перевірте її Bluetooth-протокол. Інші бренди потребують
окремого модуля підключення й обробки даних із тими самими полями показників.

Результати перевірок можна подати через пункт **«Запропонувати модель…»**
у віджеті. [Порядок участі та перевірок](../CONTRIBUTING.md).
