# BluettiWidget

Неофіційний Windows 11 віджет для зарядних станцій BLUETTI. Показує заряд,
вхідну та вихідну потужність, стан Bluetooth, історію за 10 хвилин і
орієнтовний час до розряду.

## Підтримувані моделі

| Модель | Статус |
| --- | --- |
| AC180P | Моніторинг перевірено на одній фізичній станції в попередній версії. Керування AC/DC і режимом заряджання реалізовано для незашифрованого BLE й очікує перевірки на обладнанні |
| AC180 | Експериментальний моніторинг |
| AC2A, AC60, AC70, AC70P, AC200L, EB3A | Експериментальний моніторинг. Карти регістрів перевірені офлайн за бібліотекою протоколу |

Сумісність залежить від прошивки. Зашифровані з’єднання оновлюються повільніше
й працюють у режимі читання. Віджет працює через Bluetooth LE без хмарного
акаунта, API-ключів і MQTT.

## Запуск і підключення

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe widget.py
```

1. Увімкни Bluetooth на комп’ютері та на станції. Якщо телефон уже підключився до станції, закрий з’єднання в застосунку BLUETTI.
2. При першому запуску віджет сам відкриє вікно пошуку. Вибери станцію і натисни **Підключити**. Вибір збережеться після отримання першого коректного показника заряду.
3. Кнопка **Станція** знову відкриває пошук. **Телефон** звільняє Bluetooth, а **Повернути** відновлює з’єднання. При обриві віджет повторює підключення автоматично.
4. **↗** відкриває деталі. **···** містить розміри S/M/L, прозорість та інші параметри. **×** ховає віджет у трей. Поки віджет відкритий, його значок видно на панелі завдань.

## Налаштування своєї моделі

Заряд і потужність читаються за профілем у `models.py`. Для нового профілю
додай модель із бібліотеки `bluetti-bt-lib` і перевір показники у порівнянні
з офіційним застосунком. Порядок додавання описаний в [основному README](README.md#capacity-and-model-profiles).

Щоб задати ємність, додай у локальний `settings.ini` секцію
`[capacity_wh]` і рядок на кшталт `AC180=1152`. Є зразок
[settings.example.ini](settings.example.ini). Перезапусти віджет.
Оцінка часу роботи з’являється за наявності ємності та достатніх даних про навантаження.

`settings.ini` та `logs/` створюються поруч із застосунком. Bluetooth-адреса
зберігається локально в налаштуваннях. До репозиторію додавай лише зразок.

## Збірка

```powershell
.\.venv\Scripts\python.exe -m unittest check_widget test_models test_feedback
.\.venv\Scripts\python.exe -m pip install pyinstaller==6.22.3
.\build.ps1
.\.venv\Scripts\python.exe build_portable.py
```

Переносний застосунок з’явиться в `portable/BluettiWidget.exe`.
`widget.py --demo` відкриває віджет із тестовими показниками без станції.
