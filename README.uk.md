# BluettiWidget

Відкритий віджет для зарядних станцій BLUETTI у Windows 11.
Перша версія підтримує моніторинг AC180P; AC180 додано експериментально,
тільки для читання. Інші бренди — наступний етап розвитку.

Є заряд у треї, плавна приборка, історія потужності, приблизний час роботи,
розміри S/M/L і звільнення Bluetooth для телефону. Інтерфейс український.

Налаштування особистої станції не включено: при першому запуску виберіть
свою станцію через меню `···`. Переносний exe збирається за інструкцією
в [основному README](README.md).

Статус — рання тестова версія. Моніторинг AC180P перевірено на одному
пристрої, фізичні перемикання виходів ще не перевірені. AC180 потребує
тестування власниками. Не публікуйте серійний номер, адресу Bluetooth,
settings.ini або необроблені діагностичні журнали.

Власний код — MIT; залежності мають окремі ліцензії.
