# BluettiWidget

Неофіційний Windows 11 віджет для зарядних станцій BLUETTI. Показує заряд,
вхідну та вихідну потужність, стан Bluetooth, історію за 10 хвилин і
орієнтовний час до розряду.

## Завантаження для Windows 11

[**Завантажити BluettiWidget-Setup.exe**](https://github.com/wertalya/BluettiWidget/releases/download/v0.4.2-preview/BluettiWidget-Setup.exe)
· [Сторінка релізу](https://github.com/wertalya/BluettiWidget/releases/tag/v0.4.2-preview)

Відкрий завантажений файл. Інсталятор додасть віджет у меню «Пуск» і
типово показуватиме віджет після входу у Windows. У меню **Вигляд і положення** можна вимкнути **Показувати віджет після входу у Windows**, щоб запускати його лише в треї. Видалити програму
можна в **Параметри → Програми → Інстальовані програми**.

Версія без встановлення доступна в [GitHub Actions](https://github.com/wertalya/BluettiWidget/actions/workflows/build.yml)
в архіві **BluettiWidget-Windows-preview**.

## Оновлення

Видаляти програму перед оновленням не потрібно. У меню віджета натисни
**Перевірити оновлення… → Завантажити оновлення**. Браузер завантажить
інсталятор з офіційного репозиторію. Закрий BluettiWidget через трей,
відкрий новий інсталятор і встанови поверх наявної версії, у ту саму папку.
Станція, позиція, розмір та інші параметри в `settings.ini` збережуться.
Під час оновлення залиш прапорець автозапуску ввімкненим, якщо він потрібен.

У версії 0.4.0 перевірки оновлень ще немає: один раз завантаж інсталятор
за посиланням вище. Переносну версію оновлюй, замінивши EXE після закриття
програми та залишивши свій `settings.ini` поруч.

Програма перевіряє оновлення автоматично через 30 секунд після запуску, далі
раз на 6 годин. Час перевірки зберігається між перезапусками. Повідомлення
в треї з’являється один раз для кожної нової версії: натисни його або відкрий
меню оновлень. Без інтернету перевірка тихо повториться наступного разу.
Пункт **Автоматично перевіряти оновлення** вимикає фонові перевірки; ручна
перевірка залишається доступною. Запит до GitHub не містить налаштувань
або даних станції. Preview отримує новіші preview та
стабільні випуски; стабільна версія пропускає preview. Програма не виконує
прихованого встановлення. Потрібен інтернет.

## Підтримувані моделі

Віджет розпізнає **29 моделей BLUETTI**. Моніторинг і повторне підключення
перевірено на фізичній AC180P. Інші 28 профілів експериментальні й працюють
у режимі читання. Є [повний список моделей](docs/compatibility.md).
З’єднання йде напряму через Bluetooth LE, без хмарного акаунта, API-ключів і MQTT.

## Запуск і підключення

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe widget.py
```

1. Увімкни Bluetooth на комп’ютері та на станції. Якщо телефон уже підключився до станції, закрий з’єднання в застосунку BLUETTI.
2. При першому запуску віджет сам відкриє вікно пошуку. Вибери станцію і натисни **Підключити**. Вибір збережеться після отримання першого коректного показника заряду.
3. Кнопка **Станція** знову відкриває пошук. **Телефон** звільняє Bluetooth, а **Повернути** відновлює з’єднання. При обриві віджет повторює підключення автоматично.
4. **↗** відкриває деталі. **···** містить розміри S/M/L, прозорість та інші параметри. **×** ховає віджет у трей. Типово значок є лише біля годинника. У меню **Вигляд і положення** можна ввімкнути **Показувати на панелі завдань**.

Правий клік по значку біля годинника відкриває меню із зарядом і станом
Bluetooth. Звідти можна знайти станцію, повторити підключення або змінити
вигляд віджета.

## Налаштування своєї моделі

Заряд і потужність читаються за профілем у `models.py`. Для нового профілю
додай модель із бібліотеки `bluetti-bt-lib` і перевір показники у порівнянні
з офіційним застосунком. Порядок додавання описаний в [документації сумісності](docs/compatibility.md#capacity-and-new-models).

Щоб задати ємність, додай у локальний `settings.ini` секцію
`[capacity_wh]` і рядок на кшталт `AC180=1152`. Є зразок
[settings.example.ini](settings.example.ini). Перезапусти віджет.
Оцінка часу роботи з’являється за наявності ємності та достатніх даних про навантаження.

`settings.ini` та `logs/` створюються поруч із застосунком. Bluetooth-адреса
зберігається локально в налаштуваннях. До репозиторію додавай лише зразок.

## Як запропонувати параметри своєї станції

Правий клік по значку віджета → **Запропонувати модель…** відкриває
[форму GitHub](https://github.com/wertalya/BluettiWidget/issues/new?template=model-request.yml).
Вкажи модель, прошивку, ємність і що працює. За наявності додай
перевірені назви полів або регістри. Достатньо параметрів моделі,
наприклад `AC180=1152` у секції `[capacity_wh]`. Повний `settings.ini`,
адресу Bluetooth, серійний номер та необроблені журнали залиш у себе.
Після перевірки параметри можна додати до спільного профілю.

## Збірка

```powershell
.\.venv\Scripts\python.exe -m unittest check_widget test_models test_feedback
.\.venv\Scripts\python.exe -m pip install pyinstaller==6.22.3
.\build.ps1
.\.venv\Scripts\python.exe build_portable.py
.\build_installer.ps1
```

Інсталятор (потрібен Inno Setup 6) з’явиться в `dist/installer/BluettiWidget-Setup.exe`.
Переносний застосунок з’явиться в `portable/BluettiWidget.exe`.
`widget.py --demo` відкриває віджет із тестовими показниками без станції.
